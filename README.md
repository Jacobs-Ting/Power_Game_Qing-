# 九子奪嫡 · 功能原型

直接以瀏覽器開啟 `index.html` 即可，不需要建置、套件或網路。亦可在本目錄執行 `python3 -m http.server 8080`，再開啟 http://localhost:8080 。

- `index.html`：官員面板、敘事、選項、邸報、密摺對話框。
- `css/style.css`：深色官牘風格、響應式版面與鍵盤焦點。
- `js/data.js`：既有劇情、五位隨機繼承人、線索池及結局規則。
- `js/app.js`：局內狀態、事件銜接、資源扣除、密摺與結局 UI。

每局獨立抽取隱藏繼承人；重新入仕會清空進度。此原型僅使用記憶體，重新整理不保留遊戲。

密摺每案最多兩次，終章封匣。選擇皇子與管道後按「封緘呈遞」，資源不足時禁用。管道各有清晰度、準確率與事洩風險；回覆不是確定預言。

右側「原型測試台」可直接載入三種終章情境，再選稱病告老：

1. 中庸：聖眷 50、家財 45 → 告病善終。
2. 寵極：聖眷 85 → 溫旨慰留 → 王公跪迎 → 夕惕朝乾 → 年羹堯結局。
3. 清貧：聖眷 50、家財 15 → 追賠虧空。

既有規則會先檢查敗方黨禍，再檢查聖眷 ≥ 80，或聖眷 ≥ 70 且黨援 ≥ 80 的陷阱。安全致仕需要聖眷 ≥ 35、未達陷阱、家財 25–70，且未觸發黨禍。繼位時會依新君親疏調整聖眷與黨援，判定採調整後數值。非四阿哥繼位為架空年號；年羹堯路線是借用其命運的敘事模型。

驗證：JavaScript 語法檢查、九項結局門檻案例、陷阱路線與事件引用檢查通過。尚未完成真實瀏覽器視覺驗證。

## 擴充更新

- 新增「翰苑藏鋒」「九門風聲」「故宮餘燼」三章、六個主線事件；主線共 21 案。新增事件不另扣例行壽元，避免延長劇情使角色必然老死。
- 皇子親疏指數範圍 −100～100，影響新君登基後待遇與敗方黨禍。每案可選一位皇子拜會或一位名臣請益；皇子拜會花費家財 3、增加親疏 6，不直接改變依附。
- 名臣：張廷玉、隆科多、佟國維。名臣親疏累積至 24 後，在請益時首次給予額外助力。交遊次數、資源檢查與終章封閉同時由邏輯層控制。
- 佟國維晚期互動為架空延伸，頁面已標示；新增對話不視為史料。
- 開局繼位權重：廢太子、三爺、四爺、八爺、十四爺各 20%。抽取後固定，不因拜會而重抽，避免既有密摺線索失效。調整 `js/expansion.js` 的 `SUCCESSOR_WEIGHTS` 可修改比例。
- 新增 `js/expansion.js`，在既有資料與遊戲程式之間載入，擴充原有章節與事件。

執行 `node tests/game.cjs` 可驗證權重分布、交遊資源及每案限制、名臣助力、完整主線與兩種終局。這是模擬 DOM 的邏輯測試，未涵蓋瀏覽器排版與原生對話框操作。

## 結尾史評

所有九種結局均顯示「史臣論曰」，仿清代紀傳史書筆調，並標明為遊戲擬作、非《清史稿》原文。`js/chronicle.js` 依本局選擇帶來的清望、實務變化、皇子依附、名臣親疏與結局生成評論，並摘錄最多三筆實際決策作為案牘依據。每次重新入仕清空生涯紀錄；不以慰留後暴增的數值直接推斷主角先前的操守。早逝不揭露尚未登基的隱藏繼承人，留任結局保留未完之意。

史評相關測試涵蓋九種結局、未登基保密、留任措辭、清望分支及決策摘錄，已通過；尚未完成瀏覽器視覺驗證。
